ช่วง 2-3 เดือนที่ผ่านมาหนึ่งในกิจกรรมหลักของแลปคือเล่น “เลี๊ยบตุ่ย” กันตอนกลางวัน คือเป็น “เกมไพ่” ที่ใช้ตัวหมากรุกจีนเล่น แต่เราเล่นแบบมีการประมูลด้วย (ไม่ซับซ้อนเท่า Contract-Bridge)  

ช่วงปลายเดือนมิถุนายนที่ผ่านมามีประชุมทีมวิจัย ดร.แมว ชวนให้คนใช้ Gen AI เขียนโค้ดกันเยอะ ๆ ระหว่างฟังผมเลยลองให้ Claude ช่วยเขียนเกม เลี๊ยบตุ่ย ให้เลย แล้วเอาไป host ไว้บนเครื่องที่เปิดไว้สำหรับ OpenClaw ที่ tui.peune.org

จาก version แรก ตอนนี้ก็เปลี่ยนมาหลายแบบ

- version แรกเป็น Nodejs และให้ connect เล่นได้เลย เป็น Client/Server ตั้งแต่ต้น จากนั้นก็ให้ user ต้อง login ด้วย Google เพราะจะได้เอาชื่อมาตั้ง Username ในเกม เลยทำให้ได้เรียนการทำ Google Client ที่ต้องมีพวก Client ID, Secret, Authorized redirect URIs, และ Authorized JavaScript origins กับต้องไปแก้ sub-domain บน Cloudflare ด้วย พึ่งเคยทำ 555

- ต่อมาลองให้ Claude ทำเป็น Godot client เผื่อจะทำเป็นเกมขาย แต่หวังมากไปหน่อย 555 เพราะว่าบน Google Play Store ต้องจ่ายค่า developer fee (มั๊ง จำชื่อไม่ได้แล้ว) มีคนมาเป็น tester 14 วันเลยมั๊งเขาถึงจะ OK ถ้าบน Steam ก็ต้องจ่ายค่า developer fee ที่แพงกว่า Google Play Store อีก แถมเกมแนวเดียวกันอย่าง Contract-Bridge ก็ไม่มีบน Steam ซึ่งผมเดาว่าเพราะมันเล่นยาก เลยแปลว่าทำไปก็คงขายไม่ออก เลยจบแค่ทำเป็น web แบบนี้แหละ เดี๋ยวคนเข้าเยอะค่อยไปขอ Google AdSense (เคยขอแล้วเขาว่า traffic ไม่พอ)

- ไหน ๆ จะทำให้คนเล่นแล้วเลยไปลองหาเพิ่มหน่อยว่า “เลี๊ยบตุ่ย” นี่มันมาจากคำว่าอะไร ซึ่งจากการคุยกับ Claude มั๊ง (หา chat ไม่เจอแล้ว) เหมือนจะบอกว่ามาจาก 粒 เลี๊ยบ=เดี่ยว และ 對 ตุ่ย=คู่ เป็นการออกเสียงแบบแต้จิ๋ว พอไปดูการออกเสียงแบบจีนกลางแล้วเหมือนจะเป็น “ลี่ตุ้ย” มากกว่า ดังนั้นถ้าเอาตัวจีนมาใช้ทำ cover image ของเกม คนอ่านจีนกลางก็อาจจะงงว่าทำไมเรียกว่าเลี๊ยบตุ่ย คุยกับ ChatGPT ไป ๆ มา ๆ เลยจบที่ชื่อ Tui (對) พอ

- นอกจากชื่อแล้วยังมี cover image ด้วย อันนี้ผมใช้ ChatGPT gen ให้ ซึ่งตอนแรกมันออกแนวสงคราม เพราะเป็นเกมหมากรุก ผมพยายามให้มันเสนอ idea ที่ 1) บอกว่าเป็นเกมไพ่ 2) บอกว่าใช้ตัวหมากรุกจีนเล่น 3) เล่น 4 คน  แต่ที่มันเสนอมาไม่ถูกใจสักอัน  Claude กับ Gemini ก็ไม่มี idea ที่ดี จบที่ idea ของผมเอง 555 นั่นคือเอาภาพมือคนถือตัวหมากรุกจีนคล้าย ๆ ไพ่ 4 มือ แบบใน cover image ของ post นี้

- ปัญหาต่อไปคือ UI โดยเฉพาะบนมือถือ ตอนนี้ผมว่าก็ยังทำได้ไม่ดี แต่หลัก ๆ คือผมวาดโครงก่อน แล้วให้ ChatGPT gen mockup UI ให้พอดู OK ก็ให้ Claude gen code ที่ตรงกับ mockup UI นี้ จากนั้นก็ทะยอยปรับจนพอใช้ได้ (ตวามเห็นส่วนตัว) 

- ปัญหาถัดมาก็คือ Tutorial อันนี้จริง ๆ ก็ไม่แน่ใจว่าควรทำยังไง เพราะไม่ได้อยากให้ user เลือกมั่ว เดี๋ยว tutorial จะเดินต่อลำบาก เลยไปจบที่การเตรียม hands ที่ถือไพ่ที่กำหนดไว้แล้ว และเพิ่ม recommendation ที่ช่วย guide user ว่าควรเลือกอะไร ซึ่งในระหว่า tutorial นั้นเราใช้ guide message ที่เตรียมไว้แล้ว ส่วนในระหว่างเล่นจริงเอา recommendation จาก bot ที่มีมาใส่

- การสร้าง Bot นั้นทำไปพร้อม ๆ กับการทำ Tutorial เพื่อให้เราสามารถหัดเล่นคนเดียวได้ ซึ่งผมไม่อยากได้ Bot ที่คำนวณมากนัก เลยสั่ง Claude/Codex ให้ดู code ปัจจุบันแล้วสร้าง rule-based Bots ให้ ซึ่งตอนนี้ มี Bots 3 ตัวที่เราเล่นด้วยได้คือ Grit (aggressive bidder), Nok (zero-bidder), Ice (balanced bidder) เราสามารถเพิ่มเข้าไปเพื่อให้คนเล่นครบ 4 ได้

- เพลงประกอบ ไหน ๆ จะลองใช้ Gen AI ทำเกม แล้วเลยลองใช้ทำเพลงด้วย อันนี้ผมใช้ SUNO ทำ ซึ่งผลนี่ดีกว่าที่คิด ผมเปิดเพลงที่ gen ฟังเองเพลิน ๆ ได้ยาว ๆ เลย ไว้ลองหาที่ปล่อย 555

- ตอนนี้จบที่ได้ Web Client และมี Server 2 ตัว ตัวแรกทำเรื่อง authen ตัวที่สองเป็น Game Server ที่สร้างเพิ่มได้ถ้ามีคนเล่นเยอะ (คงไม่ต้องใช้ 555) ถ้าจะเล่นก็สร้างห้อง แล้วรอคน join หรือเล่นกับ bot หรือไป join ห้องคนอื่นก็ได้ 

- สุดท้ายนี้ใครที่เล่นเลี๊ยบตุ่ยไม่เป็น ผมไม่เล่าละกันให้ไปเล่นเอง 555
